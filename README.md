## What is QWARTZ?

QWARTZ is **R-Labs' next-generation cryptographic framework** implementing the ZAB (Zero-Architecture Bypass) Generation Z protocol. It combines two revolutionary approaches:

| Mode | Description |
|------|-------------|
| **ZAB-R** (Adaptive) | Self-regulating keys generated by environment entropy |
| **ZAB-K** (Key-Based) | Post-quantum hybrid keys with auto-mutability |

### Core Features

- 🔐 **Post-Quantum Security** - Resistant to quantum attacks
- 🧠 **AI-Resistant** - Neural attack countermeasures
- 🔄 **Auto-Mutable** - Keys that evolve automatically
- 🌐 **Distributed Sync** - ZAB-Sync for multi-node operation
- ⚡ **Zero-Dependency** - Pure Rust, no external crypto libs
- 🎯 **Highly Integrable** - CLI, library, WASM-ready

## Quick Start

### Install

```bash
curl -fsSL https://raw.githubusercontent.com/lvs0/Qwartz/main/install.sh | bash
```

### CLI Usage

```bash
# Generate adaptive key (ZAB-R)
qwartz keygen --mode adaptive --output my.key

# Generate post-quantum key (ZAB-K)
qwartz keygen --mode pq --output pq.key

# Encrypt file
qwartz encrypt --key my.key --input secret.txt --output secret.qw

# Decrypt file
qwartz decrypt --key my.key --input secret.qw --output decrypted.txt

# Sync nodes
qwartz sync --peers node1:9000,node2:9000

# Verify integrity
qwartz verify --input secret.qw
```

### Library Usage

```rust
use qwartz::{ZABKey, ZABMode};

// Create adaptive key
let key = ZABKey::new(ZABMode::Adaptive)?;

// Encrypt
let ciphertext = key.encrypt(b"Secret message")?;

// Decrypt
let plaintext = key.decrypt(&ciphertext)?;
```

## ZAB-R (Adaptive Mode)

The adaptive mode generates keys **from the environment itself**:

```python
# Conceptual flow
entropy_sources = [
    cpu_micro_timing(),      # nanosecond variations
    software_fingerprint(),   # OS/version unique hash
    energy_signature(),       # local power pattern
    lattice_noise()           # hardware-level randomness
]

key = derive_from_entropy(entropy_sources)
```

### Features:
- No fixed key material stored
- Keys regenerate based on context
- Immune to key-extraction attacks
- Evolves with hardware/software changes

## ZAB-K (Key-Based Mode)

The key-based mode uses **post-quantum algorithms**:

| Algorithm | Purpose | Security Level |
|-----------|---------|----------------|
| Kyber-1024 | Key Exchange | NIST Level 5 |
| Dilithium-3 | Signatures | NIST Level 5 |
| SPHINCS+ | Hash Signatures | Stateless |
| AES-256-GCM | Symmetric | Post-quantum |

### Auto-Mutability:
Keys internally restructure at unpredictable intervals while remaining valid.
