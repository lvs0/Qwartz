# Qwartz

**Un outil d'apprentissage et de recherche en cryptographie.**

Qwartz implémente le protocole ZAB-GenZ : un système cryptographique de nouvelle
génération, conçu comme terrain d'étude.

> ⚠️ **Outil pédagogique uniquement** — pas destiné à la production.

## État

- Rust
- Éducatif / recherche — ne pas utiliser pour des données réelles
